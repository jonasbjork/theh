## Fördjupning

- [Nmap Network Scanning](https://nmap.org/book/toc.html) - den officiella dokumentationen för Nmap
- [Nmap Scripting Engine](https://nmap.org/book/nse.html) - dokumentation om NSE. Beskriver bland annat skriptkategorierna som *safe* och *intrusive*.
- [Greenbone Community Edition](https://greenbone.github.io/docs/latest/) - dokumentationen för installation, feeds och skanningsprofiler.
- [FIRST CVSS v4.0](https://www.first.org/cvss/v4.0/) - hur CVSS-poängen och vektorerna är uppbyggda.
- [Known Exploited Vulnerabilities Catalog (KEV)](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)

- [FIRST EPSS](https://www.first.org/epss/) - beskriver hur EPSS fungerar
